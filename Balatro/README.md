# 小丑牌 · JOKER'S DECK

一款致敬《Balatro》的扑克肉鸽(Poker Roguelike)单文件网页游戏。**全部代码、美术、文案、音效均为原创实现**:视觉由 CSS/SVG/Emoji 自绘,音效由 WebAudio 程序化合成,不包含任何原作素材。

## 玩法

打出手牌组成扑克牌型,得分 = **筹码 × 多倍**,超过盲注目标即获胜。用**小丑牌**(被动增益)、**塔罗牌**(强化手牌)、**星球牌**(升级牌型)、**光谱牌**(稀有奇效)和**代金券**构筑滚雪球式的Combo,连续击败 8 个 Ante 的 小盲 → 大盲 → Boss 三关通关,通关后可进入无尽模式。

- 每个小盲/大盲可跳过换取标签(Boss 必须打)
- 打赢盲注按剩余出牌/弃牌/黄金卡/持钱利息结算奖金
- 商店可购买卡牌与卡包,重掷价格递增
- 10 种牌背(部分需解锁)、牌背能力各异
- 长按(或悬停)任意卡牌查看说明;支持桌面与移动端

## 运行

无需构建、无依赖、无网络:直接双击打开 `index.html` 即可(单文件,约 180KB)。进度自动存到 localStorage,主菜单可「继续冒险」。

## 开发

```
src/
  data.js     内容数据(小丑/塔罗/…/Boss 钩子)
  engine.js   纯逻辑引擎(RNG/牌型/计分流水线/经济/商店),带 __ENGINE__ 标记段
  ui.js       渲染与动画(事件回放式计分动画)
  audio.js    WebAudio 合成音效
  style.css   视觉系统(深绿呢面 × 像素数字 × 厚底按钮)
  body.html   DOM 骨架
  fontface.css 内嵌 Press Start 2P 字体(OFL 许可,仅数字/拉丁)
build.sh      合成单文件 index.html
test.mjs      Node 引擎测试(100 项)
```

```
./build.sh    # 重新构建单文件
node test.mjs # 跑引擎测试(牌型判定/计分/经济/Boss 规则/12 局全 AI 模拟守恒)
```
