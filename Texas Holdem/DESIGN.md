# 德州扑克(Texas Holdem)· 设计方案

> 交付目标(本仓库约定):单文件 `index.html`、零外部依赖、打开即玩。
> 验收口径:**规则严谨、AI 有性格且会针对每一手牌做合理反应、终局条件只有"我赢/我输"两种、自动化测试全绿、浏览器实机可玩。**

## 1. 游戏配置

| 项 | 取值 |
|---|---|
| 桌面 | 6 人桌:你(庄家轮流参与)+ 5 个 AI |
| 初始筹码 | 每人 10,000(桌面总筹码恒为 60,000,无抽水) |
| 盲注表 | 50/100 → 100/200 → 200/400 → 400/800 → 600/1200 → 1000/2000 → 1500/3000(封顶) |
| 升盲节奏 | 每 8 局升一级(保证对局在可接受时长内分出胜负) |
| 胜负条件 | 你筹码归零 → 失败;5 个 AI 全部出局(只剩你有钱)→ 胜利。仅此两种 |

## 2. 规则实现范围(德州扑克标准规则)

- 每人 2 张底牌,公共牌按 翻牌 3 张 → 转牌 1 → 河牌 1 依次发出,四轮下注(preflop / flop / turn / river)。
- 动作:弃牌 / 过牌 / 跟注 / 加注 / 全下;行动顺序:翻牌前从大盲位左侧开始,翻牌后从庄家左侧第一个未弃牌玩家开始。
- **庄位轮转**:按钮每局顺时针移到下一个未出局玩家;小盲=庄家下一位,大盲=再下一位。
- **单挑规则**(桌上只剩 2 人):庄家是小盲且翻牌前先行动,翻牌后大盲先行动——由统一的"下一位"逻辑自然推出,已用测试覆盖。
- **最小加注**:加注至少等于"上一次加注的增量"(开局为大盲);开注最小为大盲。
- **短码全下**:不足最小加注量的全下**不重新打开**已行动玩家的加注权(只能跟/弃),但所有人仍需对新注额表态。
- **边池**:多人不同额度全下时按筹码层切分主池/边池,每层由"有资格且牌力最强"者按比例获得;**未被跟注的超出部分经分层自动退回**。
- **平分余数**:除不尽的筹码按"离庄家最近的赢家优先"分配。
- 摊牌:7 张里取最优 5 张(枚举 C(7,5)=21 组合),牌型编码为可比较整数(类别 + 决胜张)。
- 牌型排序:高牌 < 一对 < 两对 < 三条 < 顺子 < 同花 < 葫芦 < 四条 < 同花顺 < 皇家同花顺;A2345 为最小顺子(钢轮同理)。

## 3. AI 设计(核心)

### 3.1 牌力评估

- **蒙特卡洛胜率**:对当前底牌 + 公共牌,随机补全对手底牌与剩余公共牌,模拟 N 次统计获胜/平局占比(翻牌前 90 次、翻牌 150、转牌 210、河牌 280;测试模式可降速)。对手数取"未弃牌人数",胜率天然随对手数变化。
- **翻牌前修正**:叠加 Chen 公式分数(口袋对/同花/连张溢价),避免纯随机模拟低估结构牌。
- 每次决策叠加 ±2.5% 噪声,避免机器人行为可预测。

### 3.2 决策管线(每一手牌怎么反应)

```
1) 算底数:equity(胜率)、底池赔率 odds=跟注额/(底池+跟注额)、基准线 base=1/(在场人数+1)
2) 主动下注/加注:
   - 无需跟注(可开注):胜率 > base + 0.13 − 凶度×0.05 − 位置加成 → 下注
   - 面对下注(可加注):胜率 > max(base+0.09, odds+0.15) − 凶度×0.05 → 反加
   - 诈唬/半诈唬:翻牌后且对手 ≤2 人,按性格 bluff 概率主动开枪
   - 慢打陷阱:怪物牌(胜率远超基准)小概率只跟注钓鱼
3) 下注尺度:开注 0.45~0.9 底池;反加 ≥2.4×;牌力怪 + 随机 → 偶发全下;贴 stature 全下优先
4) 跟/弃:跟注门槛 = odds + (1−松度)×0.06 − 已投入比例×0.10(小注放宽 2.5%)
   - 全下跟注直判:equity ≥ odds − 3% 就跟(全下后无被再诈唬风险)
   - 短码(<6BB)翻牌前推弃模式:达到基准线直接全下
5) 行为护栏:无人可应答时不加注;加注量 clamp 到 [最小加注, 全下]
```

### 3.3 五个角色(性格参数:松度 loose / 凶度 aggro / 诈唬 bluff)

| 玩家 | 风格 | loose | aggro | bluff | 预期行为 |
|---|---|---|---|---|---|
| 🧔 老陈 | 紧凶 TAG | 0.30 | 0.80 | 0.10 | 牌少而准,频繁加注施压,小诈唬 |
| 🌧️ 小雨 | 松凶 LAG | 0.70 | 0.85 | 0.18 | 宽范围进场,翻牌后持续开枪 |
| 🗿 石头 | 紧弱 Rock | 0.15 | 0.15 | 0.02 | 只玩大牌,很少加注,被逼就弃 |
| 🤠 阿福 | 松弱鱼 | 0.90 | 0.10 | 0.04 | 什么都跟,几乎不反击,送筹码大户 |
| 👑 K神 | 均衡 | 0.50 | 0.50 | 0.09 | 标准 GTO 风,难以针对 |

## 4. 架构

```
index.html
├─ 引擎层(纯同步、无 DOM,测试可提取)   /*__ENGINE_BEGIN__ … END__*/
│   ├─ 牌与评估:eval5 / eval7 / handName / mcEquity / chenScore
│   ├─ Engine 类:发牌、盲注、下注状态机(acted/raiseSeq 处理重开权)、边池、事件流
│   └─ decideAI:上述决策管线
├─ UI 层:座位/牌面渲染、事件动画编排、人类操作面板、牌型+胜率提示、牌局记录
└─ test.mjs(node):提取引擎标记段,跑单元测试 + 全自动对局模拟
```

引擎对外只暴露:`startHand / legal / apply / decideAI / nextHand` + 事件(`deal / action / street / reveal / award / bust / gameOver…`),UI 只是事件消费者;自动化测试用同样的接口把"人类位"换成 AI 驱动整局。

## 5. 测试计划(test.mjs)

1. **牌力评估**:高牌~皇家同花顺逐级压制、踢脚比较、A2345 钢轮、公共牌成牌、平局等值,约 20 组断言。
2. **蒙特卡洛**:AA 单挑胜率 ≈0.85、垃圾牌 ≈0.35(容差断言)。
3. **边池**:两层/三层全下分层归属、平分余数、未被跟注部分退回。
4. **下注规则**:最小加注递增、短码全下不重开加注权、大盲选项。
5. **盲注与轮转**:庄位轮转、单挑时庄=小盲、第 9 局升盲。
6. **整局模拟不变量**:12 局全 AI 对局跑到终局——任意时刻 `Σ筹码+注+池 === 60,000`,每局必然结束且唯一赢家恰好拿满 60,000,无死循环。

## 6. 风险与对策

- **AI 互相无限加注** → 阈值随底池赔率收敛 + 噪声 + 全下封顶,模拟测试兜底。
- **对局拖太长** → 每 8 局升盲(封顶 1500/3000),模拟统计局数上限。
- **新手不会玩** → 桌面常驻"你的牌型 + 预估胜率"提示、跟注按钮直接显示金额,规则速查收进二级折叠(克制展示)。
