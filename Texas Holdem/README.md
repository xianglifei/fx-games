# 德州扑克(Texas Holdem)

单文件网页版 6 人桌德州扑克:**你 vs 5 位风格迥异的 AI**,每人 10,000 筹码,打开 `index.html` 即可游玩,零外部依赖。

## 玩法

- 标准德州扑克规则:2 张底牌 + 5 张公共牌,翻牌前 / 翻牌 / 转牌 / 河牌四轮下注
- **胜负只有两种**:你输光筹码即失败;清空全部 5 位 AI 即获胜
- 庄位与大小盲每局顺时针轮转(含单挑特例),盲注每 8 局升级(50/100 起,封顶 1500/3000)
- 规则细节完整实现:最小加注递增、短码全下不重开加注权、多路全下的**分层边池**、平局分池余数规约

## 5 位 AI

| 玩家 | 风格 | 行为特点 |
|---|---|---|
| 🧔 老陈 | 紧凶 | 牌少而准,频繁加注施压 |
| 🌧️ 小雨 | 松凶 | 宽范围进场,持续开枪 |
| 🗿 石头 | 紧弱 | 只玩大牌,很少反击 |
| 🤠 阿福 | 松弱 | 什么都跟,几乎不弃 |
| 👑 K神 | 均衡 | 标准打法,难以针对 |

AI 决策基于**蒙特卡洛胜率模拟**(翻牌前叠加 Chen 公式修正)+ 底池赔率 + 性格参数(松度/凶度/诈唬率),带诈唬、半诈唬、慢打陷阱与短码推弃模式。设计细节见 [DESIGN.md](DESIGN.md)。

## 界面

- 商业级牌桌视觉:呢面纹理 + 金线内嵌 + 呢面 Logo、双语角标扑克牌、花纹牌背、分色值筹码(绿/蓝/紫/金)、圆形 D 庄位钮、性格色环头像
- 全套动效:发牌从牌堆飞入、公共牌翻面、下注筹码入池归集、底池飞向赢家、筹码数字滚动、行动气泡、赢家金圈
- WebAudio 合成音效(零外部资源):发牌/筹码/过牌敲桌/弃牌/全下/获胜/升盲,顶栏一键开关并记忆
- 回合压力:轮到你时金圈高亮 + 20 秒倒计时条,超时自动过牌/弃牌;操作面板同步高亮
- 操作效率:跟注按钮直显金额;加注面板 = 最小/⅓池/½池/底池/全下 预设 + 滑杆 + ±步进;键盘 `F` 弃牌、`C` 过牌/跟注、`Enter` 加注、`←/→` 调注、`1–5` 预设
- 信息层:常驻牌型 + 预估胜率;成牌后**最优五张金环高亮**(摊牌时对手同样高亮);升盲倒计局提示
- 弃牌自动收牌(muck)、自定义重开确认弹窗、获胜彩带庆祝、观战自动加速
- 移动端自适应:加注面板整体换行收纳,记录面板折叠为抽屉
- 牌局记录面板、赢家高亮与摊牌亮牌、盲注升级提示、加速开关
