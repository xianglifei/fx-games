# fx-games · 网页小游戏合集

纯前端实现的小游戏合集，无需构建、无外部依赖，打开各游戏的 `index.html` 即可游玩。

## 收录游戏

### [Klotski](Klotski/) — 华容道

经典华容道滑块益智游戏，木质传统风格。把 **曹操** 滑到棋盘底部中央的出口即通关。

- **33 个经典名局**，按难度分 5 档（入门 → 大师），横刀立马、指挥若定、层层设防等著名布局悉数收录
- **内置求解器**：0-1 BFS 最优解搜索，提供实时提示与完整解法自动演示
- **经典计步**（同一棋子连续滑动含拐弯算 1 步），每关展示理论最少步数
- 拖拽 / 轻点 / 完整键盘操作，成绩记录存于 localStorage，移动端触控适配

详见 [Klotski/README.md](Klotski/README.md)。

### [Pomodoro](Pomodoro/) — 番茄钟

专注与休息的计时工具：**工作 25 分钟**、**休息 10 分钟**，把一天的时间看得见。

- 倒计时基于时间戳计算，后台标签页、刷新页面都不漂移；到点 WebAudio 合成提示音（工作结束清脆三连音，休息结束柔和双音）
- **今日热力图**：5 分钟一格 × 288 格的 GitHub 风格网格（24 列小时 × 12 行），25 分钟恰好 5 格、10 分钟恰好 2 格，任何开始时刻都整格对齐；工作橙红、休息青绿，进行中的格子呼吸闪烁
- **今日时间线**：每轮记录「几点几分 – 几点几分」，支持提前结束并记录实际时长（不足 1 分钟不记录），附当日小结
- 数据存于 localStorage，仅保存在本地浏览器

### [Wild Camp](Wild%20Camp/) — 露营谜题

在 6×6 棋盘上，根据树的位置放置帐篷的逻辑谜题。

- 每棵树必须紧邻一顶帐篷，且帐篷互不相邻，树与帐篷一一配对
- 单帐篷占 1 格，双帐篷占 2 格，关卡由易到难
- 磁吸电子棋盘的玩法还原，自动判对错

详见 [露营谜题 规格与规则清单](Wild%20Camp/露营谜题-规格与规则清单.md)。

### [Texas Holdem](Texas%20Holdem/) — 德州扑克

单文件 6 人桌德州扑克：**你 vs 5 位风格迥异的 AI**（紧凶 / 松凶 / 紧弱 / 松弱 / 均衡），每人 10,000 筹码。

- **胜负只有两种**：你输光筹码即失败；清空全部 5 位 AI 即获胜
- 标准规则完整实现：盲注与庄位轮转（含单挑特例，盲注每 8 局升级）、最小加注、短码全下不重开加注权、多路全下的分层边池、平局分池
- AI 决策 = 蒙特卡洛胜率（翻牌前叠加 Chen 公式）+ 底池赔率 + 性格参数，带诈唬、慢打陷阱、短码推弃
- 商业级 UI/UX：商业扑克牌面与分色值筹码、发牌/筹码归池/颁流动效、WebAudio 合成音效、20 秒回合计时（超时自动过牌/弃牌）、最优五张金环高亮、加注预设面板 + 键盘快捷键、移动端自适应
- 附 102 项自动化测试（`node test.mjs`）：牌力评估、边池、下注规则、12 局全 AI 模拟筹码守恒

详见 [Texas Holdem/README.md](Texas%20Holdem/README.md) 与 [设计文档](Texas%20Holdem/DESIGN.md)。

### [Balatro](Balatro/) — 小丑牌

致敬《Balatro》的扑克肉鸽单文件游戏：打出手牌组成牌型，**得分 = 筹码 × 多倍**，超过盲注目标即获胜，构筑滚雪球 Combo 连闯 8 个 Ante 通关（可续无尽模式）。

- **78 张小丑牌**（含 5 张传说）+ 22 塔罗 + 12 星球 + 9 光谱 + 32 代金券(16 对) + 24 跳过标签 + 28 种 Boss 盲注(含终局演出) + 10 种可解锁牌背
- 完整机制：小盲/大盲可跳过换标签、强化/版本/封印三类卡牌修饰、利息经济($5=$1)、递增重掷、卡包选取、Boss 规则(必须 5 张/禁用花色/背面对局等 23 种)
- 商业级 UI/UX：深绿呢面 × 像素数字 × 厚底按钮的原创视觉、事件回放式逐卡计分动画、WebAudio 合成音效、长按查看卡牌详情、自动存档续玩、移动端自适应
- 附 100 项自动化测试(`node test.mjs`)：牌型判定、计分流水线、经济结算、Boss 规则、12 局全 AI 模拟牌数守恒

详见 [Balatro/README.md](Balatro/README.md)。

### [Castle Guard](Castle%20Guard/) — 王城守卫

单文件中世纪冷兵器塔防：敌军沿山道进攻王城，修四种冷兵器塔守住 **15 波**进攻，通关解锁无尽模式。

- **四塔克制**：箭塔速射 / 弩炮破甲(50%→100%) / 投石机拋射溅射 / 火油台灼烧减速——护甲固定减伤，重甲要靠破甲与真实伤害来解
- **七种敌军**到黑铁男爵 Boss：盾卫顶甲、轻骑疾驰、冲车极肉（对城墙 ×3）、男爵带血条红警
- **备战期提前出战换赏金**（剩余秒数 ×2）、塔 3 级升级、卖塔返 70%、波间自动存档续玩、1×/2× 倍速
- 引擎纯逻辑标记段 + Canvas 程序化美术 + WebAudio 合成音效，移动端面板自动变底部抽屉
- 附 298 项自动化测试（`node test.mjs`）：数值/索敌/经济守恒/存档往返，参考构筑全 AI 通关校验平衡

详见 [Castle Guard/README.md](Castle%20Guard/README.md) 与 [设计文档](Castle%20Guard/DESIGN.md)。

## 怎么玩

直接双击各游戏目录下的 `index.html`（`file://` 协议也可运行），或起个静态服务器：

```bash
cd Klotski && python3 -m http.server 8734
# 打开 http://localhost:8734/
```
